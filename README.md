# HeatLens  
## Local Heat Intelligence - CSH Social Impact Ideathon 2026  
Heatlens is a concept for a system combining satellite imagery, weather data, environmental physics, and machine learning to estimate the heat risk in local areas, with more factors of geography, than simple temperature   warnings. Deploys interventions for climate risks.  

### Prototype:  
This repository contains a front-end concept, using simulated values rather than real, scientific environmental data.  
### Demonstrates:  
1.) Local thermal-risk visuals  
2.) Simulation of time  
3.) Environmental risk analysis  
4.) Intervention simulation for trees, shade structures, and surfaces with reflection  
5.) Resource recommendations  
6.) Transparent process of implemented travel from data -> physics -> AI -> intervention  
  
### Limitation:  
This is not a live health warning system, and should not be used for decisions regarding public-safety. Implementation would require further validated observation, physical models, estimates for uncertainty, privacy and security reviews, as well as expert evaluation for full usage.  
  
### Proposed product elements:  
1.) Satellite imagery  
2.) Weather and atmospheric data  
3.) Land-coverage, building data, vegetation  
4.) Physics integrated thermal model  
5.) Machine-learning calibration  
6.) Intervention simulator  
7.) Geographic Information System Visualization  
8.) Community decision making  
  
### Locally Ran:  
No installation needed  
Place all three files into one folder
Open index.html through browser  
  
### Suggested improvements:  
1.) Implement real weather and satellite data  
2.) Real GIS Data  
3.) Predictions around ground temperature  
4.) Uncertainty variables  
5.) Model populations of vulnerability/exposure without personal data exposure  
6.) Validate interventions with climate researchers and urban experts
